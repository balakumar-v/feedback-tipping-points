Measured Feedback Tipping Points

A pre-rollout audit for ranking policies
Perceptron Hackathon 2026, Problem 3  |  Balakumar V, Kishore Kumar J, K Asvitha

A. Logged data

4,000 users under the old policy.
Logged show-probabilities.
Hidden taste may drive both display and click (not logged).

B. Randomized slice

3,000 users × 10 rounds. Round 0 uniform; later rounds repeat the previous item w.p. 0.5, else uniform. Propensities known.
Repeat-heavy histories expose fatigue that logs cannot identify. Cost: uniform serving lost 24% of OBD clicks, so capped at 8,000 users.

Evidence so far (simulators)

Sealed generator, preregistered: 0/144 false approvals (95% upper 2.1%); 0/48 near-boundary; 0/48 false rejects; 26/48 correct approvals.
Linear-only also 0/144 here, so it does not prove guard or veto help. One-step gate: 144/144 false approvals.
Real data: OBD static check only. KuaiRand is planned (stretch), not yet tested.

1. Static layer (MVP)

IPW · SNIPS · DM · cross-fitted DR on round-0 logs
User-level Poisson bootstrap, 95% intervals (B = 30)
ESS/n warning on thin overlap
Output: static round-0 lift
Example: +0.084 (true 10-round −0.019)

2. Fatigue models + forecast

logit(click) = base(context, item) + f(c) + round term
c = user's earlier showings of the item
Four shapes f: c · log(1+c) · 0.7-discounted recency · c + max(c−2,0)
Plus a free-form model: one coefficient per count (1…6, ≥7)
10-round rollout of both policies, anchored: subtract old policy's logged-minus-modelled reward
Output: 10-round lift + 95% interval

3. Tipping point

Bisection finds κ*, the linear fatigue strength where forecast lift = 0.
margin = Φ( (κ-hat − κ*) / SE )
SE = bootstrap SD of κ-hat. Reported as a diagnostic, not a verdict input.

4. Safety rules

• All four shapes agree (lower ends > 0)
• Coverage guard: ≤ 5% of forecast showings above the largest repeat count the slice shows 100 times
• Free-form veto: its lower ends > 0 too
• Logs-only audits never APPROVE

REJECT

Under all four shapes, the static or the 10-round upper 95% end ≤ 0.

NEED RANDOMIZED DATA

Anything else: shapes disagree, an interval spans 0, guard or veto fails, or no slice. Reports extra data size.

APPROVE

Static and 10-round lower 95% ends > 0 under all four shapes, and all safety rules pass.
